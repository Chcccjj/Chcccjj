## 🔭 Focus

- **Interactive 3D**：用 Three.js / WebGL 构建可探索的建筑空间，让镜头、灯光与机械结构成为交互的一部分。
- **Computational Physics**：把振动模型、数值积分与数据分析放进浏览器，通过调参、实验和可视化理解物理。
- **Accessible Experiences**：关注多语言界面、触控操作和离线使用，让作品更容易打开与体验。
